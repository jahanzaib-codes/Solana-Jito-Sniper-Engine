# 🤝 Contributing to Solana-Jito-Sniper-Engine

Thank you for contributing to **Solana-Jito-Sniper-Engine**! We welcome contributions from blockchain developers, Rust/Python engineers, and MEV researchers.

## 📋 Code of Conduct
We maintain a professional, collaborative, and inclusive environment.

## 🛠️ Development Setup
1. **Fork and Clone:**
   ```bash
   git clone https://github.com/<your-username>/Solana-Jito-Sniper-Engine.git
   cd Solana-Jito-Sniper-Engine
   ```
2. **Environment Setup:**
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

## 🚀 Pull Request Process
1. Verify that `flake8 . --count --select=E9,F63,F7,F82` passes with zero errors.
2. Update documentation and changelogs.
3. Submit PR against `main`.
