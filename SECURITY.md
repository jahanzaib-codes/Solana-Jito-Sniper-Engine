# 🔒 Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We prioritize private key security, transaction signing safety, and anti-drainer protections:

1. **Do not disclose publicly:** Please avoid opening public GitHub issues for private key vulnerabilities.
2. **Contact Channel:** Reach out directly via Telegram at [@JanzebBlockdev](https://t.me/JanzebBlockdev) or verified portfolio links.
3. **Response Timeline:** Acknowledged within 48 hours.
